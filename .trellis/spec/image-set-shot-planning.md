# 套图逐图取景与卖点覆盖

2026-11-07 经 Q4、Q5、Q8、Q9 确认。内置与高定模式均已在 v0.13.0 工作区实现。使用同一张合成套装参考做了首轮验收，高定三张分别展示整套、按键特写和独立刷头，内置 `style1` 的两个 Feature 图位也分别呈现按键和刷头。测试命令、样图位置和交接状态见[验收记录](../research/font-master-shot-planning-validation.md)。

## 首轮逐图规划

1. 在已有中文方案总览中，按实际输出顺序列出每一张的**用途或核心卖点、画面主体、取景范围与角度、实物依据**。实物依据写到“哪张外形参考能看见哪个部位”。卖点和配件归属以已确认的产品资料为准。
2. 在用户确认前横向比较这些图位。产品全貌、整套关系、单件、单配件、局部特写和使用动作按用途安排。两张图若展示同一整套和同一视角，单换背景或标题不算新的产品展示。按各张要回答的购买问题调整，再一起确认。
3. 将每行决定写入对应图的**初始 prompt**，指明这一张取哪些部位、哪些配件需要入镜。整套实拍可作为所有图的外形依据，某张图只需其中一个部位时，明确要求单独取景。按确认张数生成并交付即结束本轮流程。生成后自动追发消息的 hook 和自动重画在本轮范围之外。

内置按所选图片类型和每类数量安排图位，已有逐图规划的风格复用其 Coverage Matrix。高定 v4 按仿照图选择顺序一图一张，旧 v3 按卡片逐张生成。逐图规划在既定数量与顺序内完成。单图任务按用途选镜头，跨图覆盖仅适用于套图。

## 取景与优先级

- **核心卖点图一张只讲一个已确认的卖点。** 只展示能说明这个卖点的主体。接口卖点可以只拍接口，套装清单图则可用全貌讲清随附内容。
- 已确认是多件套，且有合适图位和可辨认的实物依据时，至少一张以单件或单个配件为唯一产品主体。整套全貌出现几次由图位用途决定。单件展示沿用实际的套装销售关系。单品可用真实局部、不同视角或使用动作拉开差异。
- 新视角、特写和配件均须有实物依据。即使只有一张整套照，也可放大其中看得清的部分。背面、内部或接口看不清时，改选可证实的部位。套装数量以已确认资料为准，不能从参考图张数推断。
- 高定仿照图决定文字区、信息层级和版式。产品展示范围、景别和有依据的角度由本张卖点决定。即使仿照图画了整套，单配件也可以成为唯一主体。用户明确指定某张展示整套时，以该要求为准。高定字形与配色见[字体母版规范](./customer-reference-library.md#高定字体母版)。

## 验收示例

假设同一张实拍清楚展示主机、主机按键和随附刷头，产品资料也确认刷头随套销售。三张图可以共用这张外形参考。

| 图位 | 回答的购买问题 | 首轮应呈现的画面 |
| --- | --- | --- |
| 套装总览 | 包含哪些东西？ | 主机与刷头的完整关系 |
| 按键卖点 | 操作键在哪里？ | 只取实拍可辨的按键区域，即使仿照图展示全套，也保留其文字区和版式 |
| 配件介绍 | 随附的刷头什么样？ | 刷头独立入镜，按实拍可见角度展示其外形 |

在这个例子里，如果三张初始 prompt 都要求全套入镜，即使背景各异，方案也应在确认前修正。实现验收时用同一组素材生成样图，逐张对照已确认的镜头。按键图的焦点应落在按键，配件图的产品主体应只有刷头。
