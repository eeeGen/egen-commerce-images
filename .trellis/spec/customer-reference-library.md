## 范围与风格来源

- 高定模式对应 `taskOptions.styleSource = customer-reference`。新图库菜单仅用于此模式。
- 内置与高定模式均停用旧固定图库 `E:\e-commerce\knowledge`，移除 skill 中的固定路径、补充图库参考和按图片类型匹配图库文件的规则。
- 内置模式保留现有 style 菜单及 `references/style-prompts/` 文档；风格仅来自所选内置 prompt，产品事实和外观来自当前产品素材。保留与图片类型对应的 prompt 章节选择。
- 高定模式的风格来自用户显式选中的本地图片，不加载内置 style prompt，不套用内置选图规则。风格图不作为当前产品事实或外形依据。
- 本次验收 Windows 跨电脑、跨盘符；设计保留 macOS/Linux 扩展能力，不承诺本次已适配。
- 只支持一个当前图库及其 style 菜单。图库搬运、文件同步、多图库管理和增量索引缓存不在本次范围内。

## 表单入口

- 用户提供产品实拍图或其本地路径后，优先实际启动并打开本地表单；只有启动、健康检查或浏览器打开的具体尝试失败，才使用 Markdown 回退，并说明失败原因。

## 手动路径清理

- 高定模式的手动文件及目录路径统一先清理首尾空白，再去掉包住整个路径的一对英文双引号；保留路径内部内容。不扩展为单引号、中文引号或残缺引号修补。
- 适用于外形参考图、仿照图、色彩母版和产品信息文档等手动路径。Markdown 回退用路径表示选中的字体母版时也做相同清理，候选范围与表单相同。
- 此规则仅处理字符串，不新增路径存在性或有效性检查；图库定位和已有素材读取、扫描流程仍各自执行其必要操作。
- 示例：`  "D:\图库\参考图.png"  ` → `D:\图库\参考图.png`；路径中的中文、空格和其他内部字符不改写。

## 图库发现与首次绑定

统一标记文件为图库根目录中的 `.imglib.json`。所有新图库取图入口共用同一定位流程，不写死某台电脑的图库路径。

按优先级定位：

1. 环境变量 `IMG_LIB`。设置后必须定位到带标记的图库；无效时显示提示并让用户重新选择，不静默改用其他图库。
2. 用户配置 `~/.codex/skills/image-library/config.json`，保存发现规则而非机器专属的绝对图库路径。可用卷标与相对提示定位；历史定位失效则继续自动探测，卷标读取失败不阻断后续发现。
3. 自动探测当前工作区、当前用户的图片/文档/桌面目录，以及本机已挂载的本地盘和移动盘。实际枚举目录和盘符，不固定为设计稿中的 `D:/`、`E:/`。
4. 仍未找到时打开系统文件夹选择框，让用户选择图库根目录；缺少标记则自动创建，并保存发现规则。无桌面环境才使用拖入或输入路径的引导。取消选择后仍可使用手动参考图入口。

自动扫描约束：

- 每个候选根目录算深度 0，最多下探 5 层查找标记；这是图库发现深度，不是 style 内的图片扫描深度。
- 跳过无权限目录、`.git`、`node_modules`，不跟随目录链接，不自动扫描网络位置。
- 高优先级定位成功后，不再广泛扫描。对同一优先级的多个图库候选，让用户选择并记住，不直接取首个结果。
- 找不到图库时提供首次引导；不承诺任意位置均能被限深扫描发现，也不自动同步图库文件。
- 同一表单服务同时只打开一个系统文件夹选择框；重复点击或自动发现请求交叠时，不层叠弹出多个选择窗口。

## style 菜单与选图状态

- 图库根目录的每个直接子文件夹对应一个 style，菜单名称使用原文件夹名。
- style 菜单与「手动指定参考图」互斥。选择 style 后自动展示该文件夹直属图片，不递归；选择手动入口后才输入参考图路径。
- 用户仍须选择仿照图和单张色彩母版；选 style 不等于自动选择所有图片。图片格式沿用现有规则；产品图维持 50 张上限，图库 style 与手动风格目录展示全部直属图片，不受原 30 张上限截断。
- 切换 style 或切换手动/style 来源时，清空旧仿照图选择、色彩母版和字体母版，保留产品图。
- 启动或手动刷新时重新读取目录。刷新同一 style 时保留仍存在的选择及顺序，移除失效选择并提示；母版失效时同样清除并提示。
- 没有可用图片的 style 保留在菜单中，但禁用并说明原因。
- 沿用 [客户参考风格工作流](../../plugins/egen-commerce-images/skills/egen-commerce-images/references/customer-reference-workflow.md)：共用产品图、按用户选择顺序逐张生成、单张色彩母版不增加生成数量。

## 高定字体母版

- **表单与回退。** 高定用户可以选零或一张字体母版，也可以清空选择。与色彩母版共用选图入口，候选只取当前图库 style 或当前手动风格目录展示的图片。同一张图可以兼任字体母版、色彩母版或仿照图。仅被选作母版的图片不占出图名额。
- **任务数据。** 表单保存字体母版的选择，服务端从当前已扫描的风格图片中解析所选图片的路径。Markdown 回退同样只接受当前候选。未选或旧任务缺少此项时，每张图沿用自己的仿照图字体。刷新同一 style 时分别保留有效的两项母版选择，清除失效项并提示。
- **方案与逐图 prompt。** 确认总览显示字体母版文件名，未选时说明字体随各张仿照图。若选中的图没有可辨文字，在确认方案前请用户换图或清空。每次生成带排版文字的图，都把同一张母版图片用作字形参考，并在本张 prompt 中明确标题、正文及相应层级标注各自匹配的字形和字重。仿照图决定文字区位置、层级和版式。验收以母版可见字形为准。
- **字色与实物。** 字体母版只提供字形，字色按当前画面的可读性选择。整体配色沿用色彩母版与 `colorPriority`，保留 `master`（母版优先）、`scene`（场景优先）、`auto`（总览说明建议后确认）。无文案图保持无字，产品及包装原有印字按实物参考还原。

## 验收要点

| 场景 | 预期 |
| --- | --- |
| 手动路径包含首尾空白和外围成对英文双引号 | 只做规定的字符串清理，不增加路径检查，不修改内部内容 |
| 两台 Windows 电脑盘符或用户名不同 | 通过发现规则、自动扫描或首次文件夹选择定位，不要求手输路径 |
| 图库位于当前工作区 | 工作区作为独立扫描候选根目录参与发现 |
| 标记位于候选根的第 5/6 层 | 第 5 层可发现，第 6 层不扫描；需要时进入首次引导 |
| IMG_LIB 无效 / 历史配置失效 | 前者提示重新选择且不静默换库；后者继续自动探测 |
| 同一优先级发现多个图库 | 用户选择并记住，不自动选首个 |
| 首次选择无标记图库 / 取消选择 | 前者创建标记并保存规则；后者保留手动入口 |
| style 中包含子文件夹 | 仿照图只取直属图片，不递归 |
| style 中超过 30 张直属图片 | 全部展示并可选；手动风格目录同样不截断 |
| 切换来源 / 刷新同一 style | 前者清空仿照图和母版；后者保留有效选择、移除失效项并提示；产品图保留 |
| 空 style | 菜单可见、禁用并说明原因 |
| 内置或高定模式生成 | 均不读取旧固定图库；内置使用所选 prompt，高定使用用户选定的图片 |
| 字体母版留空或读取缺少该项的旧任务 | 可继续规划并按各自仿照图用字。色彩母版仍为必选 |
| 两张仿照图字体不同，另选一张含两种字体的母版 | 两图的标题分别匹配同一母版标题，正文分别匹配同一母版正文，输出仍为两张 |
| 字体母版字样为红色，色彩母版为蓝调且选择 `master` | 画面采用蓝调，标题和正文按字体母版匹配字形，字色按背景对比选择 |
| 仅选作字体母版的图无可辨文字 | 确认方案前提示用户换图或清空选择 |
