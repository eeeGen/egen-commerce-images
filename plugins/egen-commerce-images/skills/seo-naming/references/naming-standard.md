# Product Image SEO Naming Standard

## Naming Pattern

```text
productcode-##-type-seo-keywords.ext
```

Example:

```text
a003-01-hero-flatware-set-32-piece-service-for-8.png
```

The filename begins with product code, display order, and image type. SEO keywords come after the type.

## Purpose

SEO-friendly product image filenames are a low-cost supporting signal. They help search engines, marketplace systems, CDNs, and internal databases understand and manage image assets. They do not guarantee ranking, traffic, or sales improvements.

## Hyphen Rule

Use `-` for file names and URLs because it is widely treated as a word separator. Use `_` for database fields and code identifiers.

```text
Filename: a003-01-hero-flatware-set-32-piece-service-for-8.png
Fields: seo_filename, image_type, sort_order, product_code
```

## Type Definitions

- Hero: best primary image; product subject clear and commercially strongest.
- Selling: pain point, selling point, buyer benefit, or why-buy message.
- CoreA/CoreB: major value scenarios, such as family dinner, gatherings, hospitality, or business use. CoreA用第一个核心场景承接卖点，让用户看到产品最主要的使用价值。CoreB补充第二个核心场景，扩大适用人群或使用场景覆盖面。
- Feature: material, design, structure, or functional detail.
- Specs: dimensions, quantity, included pieces, or components.
- Value: complete-set value, differentiation, or value proposition.
- Compare: comparison versus loose pieces, competitors, or inferior alternatives.
- Lifestyle: real usage scene or table result.
- Guide: use, care, cleaning, installation, or instruction content.
- Closing: final A+ summary or closing banner. 展示品牌感、情绪收束、购买理由总结，形成完整闭环。

## Type Order

```text
01 Hero
02 Selling
03 CoreA
04 CoreB
05 Feature
06 Specs
07 Value
08 Compare
09 Lifestyle
10 Guide
11 Closing
```

Types can be missing or repeated. Do not force one image into every type if the content does not support it.

## SEO Keyword Selection

Use real marketplace/category terms from the target market. For Mercado Libre Mexico, prefer Spanish Mexico terms from same-category top listings, search results, filters, and visible product attributes.

For flatware/cutlery examples:

```text
juego de cubiertos
32 piezas
acero inoxidable
plateado
plata
servicio para 8
cuchillos
tenedores
cucharas
cucharillas
apto para lavavajillas
facil limpieza
uso diario
mesa
comedor
```

Avoid stuffing all synonyms into one filename. Choose 1-2 natural keyword phrases per image after the type.
