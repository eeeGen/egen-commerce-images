# style6-v3 品牌官网式情绪叙事图组系统

## 定位与 A/B 对照契约

`style6-v3` 用于品牌官网、A+ 页面或强调质感和使用想象的产品叙事。它以产品为真实主角，先建立情绪、空间和触感，再用克制信息帮助理解；不是去除事实，而是把事实放进更有节奏的故事里。

与 `style6-v2` 对照时，必须使用完全相同的产品事实、身份参考、图片类型、比例、目标市场/语言、可见文案事实和安全区。不得借由更换产品资料、增加虚构配件或修改卖点来制造差异。

## 绝对事实边界

- 产品图片是外形、颜色、材质、结构、接口、包装和配件的唯一事实来源。
- 多张参考图用于校准同一真实产品的多角度，不等于可在画面中复制出多个实例。
- 只有包装清单或实拍可证明的组件才能共同展示为套装。
- 不虚构功能、内部结构、认证、尺寸、人物身份、使用效果或品牌历史。
- 顶右角始终预留自然 logo 安全区，不显示占位元素。

## 产品参考角色

为每张图选择最少且最相关的产品参考，并标记：`identity-anchor`（整体外形）、`view-proof`（另一视角/接口）、`set-proof`（真实套装关系）、`detail-proof`（材质或结构细节）。

只传入当前镜头需要的 1--4 张图。除非真实资料明确是多个组件，不得因有多张参考而绘制产品阵列、重复产品或不真实的多包装。

## 套图叙事曲线

在撰写任何单图 prompt 前，先建立一张 set-level Coverage Matrix，记录每张已选图片的叙事段落、产品形态、真实证据、场景/时段、机位、信息密度与避重复策略。Coverage Matrix 仅使用用户确认的产品事实，不能把多张参考图误判为多件产品。

选中的图片类型应在下列曲线中各承担一个不同段落，而非每张都是海报：

| 类型 | 叙事段落 | 产品呈现 |
| --- | --- | --- |
| Hero | 初见：产品的气质与真实存在感 | 单品或已验证套装 |
| Selling | 发现：一个值得靠近的真实价值 | 单品加局部证据 |
| CoreA | 融入：最典型的使用时刻 | 使用中的产品 |
| CoreB | 延展：另一个空间、时间或人群 | 不同场景与角度 |
| Feature | 触感：材质、结构或操作细节 | 微距/局部 |
| Specs | 了解：形态、尺度或包装事实 | 克制多视角 |
| Value | 感受：事实支持的选择理由 | 产品加少量价值节点 |
| Compare | 辨别：可证实的不同 | 客户产品与中性对照 |
| Lifestyle | 日常：产品带来的生活片段 | 环境中的单品 |
| Closing | 回望：整套故事的静态收束 | 单品或真实套装 |
| Guide | 开始：自然、可信的第一步 | 连续操作步骤 |

若只选少量图片，优先做“初见、触感/多视角、主要使用时刻、收束”四种不同段落。新镜头与前图至少改变四项：产品形态、景别、机位、空间、时间/光线、叙事动作、信息密度。

## 视觉导演语言

v3 的共同气质是安静、可信、具有材料和空间感。根据 `{product_category}`、`{material}`、`{use_context}` 与 `{scenes}` 中已确认的信息，选择一个最合适的主题，例如“晨间准备”、“有序收纳”、“专注工作”、“周末出行”或“安静的居家仪式”；若没有场景事实，则采用无人物的工作室静物叙事。

每幅画面采用五层空间，而不是堆叠信息面板：

1. `氛围背景层`：真实空间、柔和渐变、材质桌面或干净影棚，带前后景深。
2. `叙事环境层`：仅由确认场景支持的手部、桌面、收纳或生活线索。
3. `产品主体层`：一个清晰主产品或经确认的套装，保留真实比例和边缘。
4. `触感/证据层`：一个局部高光、微距裁切、真实配件或克制引线，帮助读懂事实。
5. `编辑层`：留白、简短排版、细线、柔和半透明标签、颗粒和微光；绝不遮挡主体。

主产品通常占 38%--62% 画面。以自然窗光、柔和侧光、反射控制、真实接触阴影和低饱和色彩统一系列；深蓝与金色只作为极少量编辑强调，不强行套用技术 UI。

## 动态镜头配方

不要把 v3 变成固定诗意句式。每张图先基于真实资料输出以下配方，再扩展为 Image Gen 指令：

```text
故事瞬间：<一个由确认场景支持、能被看见的时刻>
观者感受：<从产品特征合理推导的情绪，不夸大效果>
产品形态：<单品 / 已验证套装 / 微距 / 使用中>
真实证据：<本图只允许展示的组件、结构、卖点、规格>
镜头：<景别、机位、焦点、前中后景、产品占比>
空间层次：<背景 → 环境 → 产品 → 证据 → 编辑层>
排版：<标题、正文、标签或完全留白；使用目标语言>
光色：<实际光源、材质反射、系列色彩关系>
避免：<重复姿态、密集 UI、虚构道具/功能、过度电影特效>
```

最终 prompt 必须明确：所有文字只使用已确认的 `{headline}`、`{subheadline}`、`{selling_points}`、`{specs}`、`{accessories}`、`{scenes}` 与 `{use_context}`；没有事实不补写；用户产品始终可辨识；所有文字使用 `{language}` 且简短清晰。

## style6-v3 分镜指令

### Hero — 初见与存在感

- 以单个核心产品为首选；若真实包装清单证实为套装，则用自然前后层次展示套装关系，而非电商式平铺。
- 使用雕塑般的 45° 或低机位静物构图，背景保留可呼吸的负空间；标题最多一主一副。
- 材质高光、接触阴影和背景色块建立第一印象，不使用 v2 式图标矩阵或参数带。

### Selling — 发现一个真实价值

- 选择一个真实卖点，并让产品与一个细微证据同框：例如可见结构、材质触感或已确认使用动作。
- 主体为中近景单品；文本像编辑标题，最多一条短解释和一个低调标签。
- 构图要与 Hero 改变机位或画面重心，避免重复“产品居中海报”。

### CoreA — 最典型使用瞬间

- 从 `{scenes}` 选择最具代表性的真实场景，让产品自然参与一个可见动作或准备动作。
- 使用真实空间光线、手部或环境细节建立代入感，人物不看镜头、不作为代言。
- 只放一句事实性标题；情绪由画面、空间和材质表达，而非夸张文案。

### CoreB — 另一段生活节奏

- 与 CoreA 改变场景、时段、使用者、动作、机位或色温中的至少两项。
- 将产品置于另一种经确认的高价值时刻，如移动、整理、分享、结束使用或不同空间；资料未支持时不猜测。
- 采用更宽或更紧的景别来改变节奏，文字保持极少。

### Feature — 触感与可见结构

- 用一张真实、精确的微距来表现产品的表面、按键、接口或可见结构；不得创造内部零件、爆炸图或科技能量。
- 可在边缘保留一小段完整轮廓，用一条极细引线解释已确认特征。
- 重点是真实材质、光影、边缘和手感，而不是技术面板。

### Specs — 克制的形态证明

- 用 2--3 个有节奏的不同视角、真实尺寸线或经确认的包装关系帮助理解产品。
- 若没有数值，专注正侧背形态或结构差异；若有数值，使用简洁编辑式标注，不做拥挤表格。
- 背景接近画册留白，避免生活场景和复杂特效。

### Value — 值得长期拥有的理由

- 以单品为中心，围绕最多三个真实价值点建立稀疏、非对称的图文关系。
- 可使用一个材质微距、一段场景色块或真实配件作为视觉回声；不列出未经确认的“六大优势”。
- 排版像品牌编辑页：大留白、层级明确、深色正文和一处低饱和强调色。

### Compare — 安静的可验证辨别

- 只比较可证明差异；对照对象是无品牌、非特定、通用的替代物，不复制竞品外观。
- 用材质、结构、收纳关系或已确认包装事实制造对比，不使用贬损文字、红叉堆叠或绝对性能话术。
- 让客户产品在光线、焦点和细节上更清晰，但不夸张成虚构效果。

### Lifestyle — 日常篇章

- 以一个单独的真实生活片段为核心，产品自然融入空间、手部或桌面活动中。
- 使用环境前景遮挡、柔焦背景和真实光线创造层次；产品仍必须容易辨认。
- 可以无文字，或仅有一句短标题；避免 v2 的卡片、参数和浮动图标。

### Closing — 余韵式收束

- 回到单品或真实套装，用与 Hero 不同的角度、光线或背景，形成更安静的最终静物。
- 使用已提供的品牌名/产品名（如有）和一句简短事实性价值总结；不可编写品牌故事、奖项、折扣或平台标识。
- 可使用低饱和深蓝渐变、柔和金色边光或纸张/织物等已合理的背景纹理，保持克制。

### Guide — 自然的第一步

- 用 2--4 帧连贯、真实的操作瞬间展示开始使用；每一帧必须由可确认的产品/配件/动作支持。
- 编号与短动词采用低干扰编辑排版；视线沿产品和手势自然流动。
- 不杜撰安装、维护、清洁、充电或安全步骤，背景维持同一安静空间以突出操作。

## A/B 验收

- v3 在首眼应更像品牌官网或 A+ 编辑页：空间更大、文字更少、质感与故事更强。
- 产品的真实外形、真实组件与真实卖点仍清晰可核对，不能为了氛围牺牲商品辨识。
- 整套图的场景、景别和动作具有章节感，没有反复的居中单品海报或全产品排列。
- 相比同输入的 style6-v2，v3 应明显降低模块化 UI 密度、提高环境层次与情绪连贯性，但不得增加任何未经证实的事实。
