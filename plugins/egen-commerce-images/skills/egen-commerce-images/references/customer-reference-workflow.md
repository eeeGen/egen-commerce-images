# 客户参考风格工作流

当保存的任务 JSON 中 `taskOptions.styleSource` 为 `customer-reference` 时使用本参考；风格来源是客户选中的本地图片。

## 任务资料

schema v4 使用服务端解析的 `referenceWorkflow.productImagePaths`（至少一张共用外形图）、`styleReferencePaths`（至少一张仿照图，按选择顺序）、`colorMasterPath`（必填的单张色彩母版）、`colorPriority`（`scene`、`master` 或 `auto`）和可选的 `fontMasterPath`（单张字体母版）。这些字段均属于 `referenceWorkflow`。生成时只使用已解析路径。母版可同时用作仿照图或另一种母版，出图数只由仿照清单决定。

客户参考模式不要求 `knowledgeStyle`、`imageTypes` 或 `quantityPerType`。schema v4 校验外形图、仿照图、色彩母版和全局色彩策略。已保存的 schema v3 任务要求 `colorMasterPath`，并至少有一张输出卡，每张卡必须有非空名称、1–4 个 `productImagePaths` 和一个 `styleReferencePath`。沿用每卡的 `colorPriority`、`ratioOverride`、`intent` 和 `copyOverride`，每卡生成一张。必填选择不完整时一次性指出缺项。旧任务按原 schema 读取，字体字段缺失或留空时，各图沿用自己的仿照图字体。

外形参考图直接校准产品外观；不要以文字描述替代或扩展产品的外形、比例、颜色、材质、结构、接口、配件和细节。参考图画幅不决定输出比例；v4 使用 `taskOptions.ratio`，v3 使用全局比例或卡片的 `ratioOverride`。

色彩母版只提供跨图片的调色方向。将其色彩倾向写为调色约束，仅作色彩母版的图片无需另传。`colorPriority` 为 `scene` 时优先保留当前仿照图的大面积场景环境色，为 `master` 时优先遵循母版，为 `auto` 时在总览中说明建议并让客户确认。

选了字体母版时，先查看该图，分别识别标题、正文等可辨字样的字形与字重。图片无法读取或没有可辨文字时，在确认方案前请客户换为当前风格里的另一张图或清空选择。母版仅约束新增排版文字。字色按画面对比选择，产品和包装原有印字按实物还原，无文案图保持无字。

## 生成配方总览

生图前用中文列出共用外形图、按生成顺序排列的仿照图、色彩母版及色彩策略、字体母版文件名（未选则标明“各图沿用各自仿照图字体”）和最终比例。按主流程的逐图取景表，将每张仿照图与本张卖点、主体、镜头、实物依据和文案对应。v3 逐卡列出名称、意图及对应图片。客户可在现有确认环节修改，确认后逐张生成。

文案来自已确认的产品资料、额外要求、平台和目标语言。仿照图提供文字区位置、层级、密度及通用组件语言。已选字体母版时，标题和正文各自按母版相应字样统一。

## 逐张生成

v4 按 `styleReferencePaths` 的顺序，每张仿照图独立调用一次 `image_gen.imagegen`。`referenced_image_paths` 先放全部共用外形图，再放当前这一张仿照图。v3 每次使用本卡的产品图和仿照图。本张有新增排版文字且已选字体母版时，再附上 `fontMasterPath` 对应的原图。相同路径只传一次，在 prompt 内按实际输入顺序标清各图承担的角色。字体母版只参考字样，不引入其中的产品、版式、颜色或文案。

每张初始 prompt 写入取景表中本张的卖点、唯一主体或套装关系、取景范围、角度和可见依据。仿照图决定文字区、层级、场景与版式节奏。产品按本张卖点取景，即使仿照图展示整套，也可只拍实物参考中可辨认的一个配件或局部。用户明确指定整套展示时按其要求生成。

有字图在每条 prompt 中分别指明标题、正文及对应标注匹配哪个参考字样和字重。未选字体母版时从本张仿照图取字形。加入已确认的文案、配色策略、比例、光线和通用安全区要求。将仿照图中的品牌、商标、平台标识、人物脸、角色/IP、独特插画和受保护文案替换为中性、功能等价元素。产品事实须有资料支持。

生成后直接交付所有结果；不做自动视觉核验或自动重试。按原有输出归档规则保存，v4 使用仿照图文件名的文件安全主干和两位生成序号，v3 使用文件安全的卡片名称，并将 style token 记为 `customer-reference`。
