## 二、缺陷修复明细

### D1 最终记录含推断成分，存在潜在漏读

- **所属模块 / 类型：** 流程合规 / 模型注意力管理
- **严重程度：** 高
- **是否可复现：** 是
- **问题描述：** 模型一次性查看全部图片，中途无逐图更新；最终记录混入推断且过于简单，存在漏读。
- **复现步骤：**
  1. skill 要求逐张查看并在每张图后更新信息记录。
  2. 实际执行时一次性将全部图片送入上下文，中途无逐图更新动作。
  3. 最终输出记录中混入对图中未明示信息的推断内容。
- **评测结论：**
  - 归因：**注意力管理与流程纪律双重缺失**。一次性将全部图片送入上下文，注意力被分散到多张图，单图信息信噪比下降；缺少"每图一记录"的强制锚点，信息未被逐张固化与核对。
  - 判定依据：违反"逐张查看 + 逐张记录"流程；证据与推断未分离，缺少可追溯的逐图证据链。
  - 影响：记录可追溯性下降；推断内容可能被误当作图中明示信息；潜在漏读不可检出。
- **修复状态：** ✅
- **修复方案：** 修改 Info-skill workflow。

### D2 Base64 批量输出导致终端截断

- **所属模块 / 类型：** agent 工具使用
- **严重程度：** 高
- **是否可复现：** 是
- **问题描述：** 将 20 张 PNG 转为 Base64 输出到终端，输出量过大被截断，图片内容未被看到。
- **复现步骤：**
  1. 选择以文本形式（Base64）传输图像数据。
  2. 一次性转换 20 张 PNG 并输出到终端。
  3. 输出量超过工具上限被截断，图片内容未实际读取。
- **评测结论：**
  - 归因：**agent 对工具使用认知错误**。方法选择错误；图片数据当文本传输，低效且必然触及工具输出上限。
  - 影响：本轮读取完全无效，浪费一轮执行。
- **修复状态：**✅
- **修复方案：** 修改 Info-skill workflow。

### D3 fallback为预览图后工具失效

- **所属模块 / 类型：** agent 工具使用
- **严重程度：** 高
- **是否可复现：** 是
- **问题描述：** 生成缩小图后再次尝试 Base64 输出到终端，重复 D2 的失败模式；随后 Codex 文件预览仅返回 `queued`，未确认预览是否显示、读取到什么。
- **复现步骤：**
  1. 改用预览图方案，但再次以 Base64 输出到终端，重复 D2 失败模式。
  2. 调用 Codex 文件预览，返回值仅为 `queued`。
  3. 未对预览结果做有效性校验，无法确认是否真正读取到内容。
- **评测结论：**
  - 归因：**agent 对工具使用认知错误**。同一错误模式重复出现，且未对工具返回值做有效性校验。
  - 影响：预览环节形同虚设，未产生任何可用证据。
- **修复状态：**✅
- **修复方案：** 修改 Info-skill workflow。

### D4 替代方案未穷尽即中止并转嫁用户

- **所属模块 / 类型：** 执行判断
- **严重程度：** 中
- **是否可复现：** 是
- **问题描述：** 直接将"工具无法读取图片"等同于"任务无法继续"，请用户重新上传。
- **复现步骤：**
  1. 工具读图受阻。
  2. 未先探索当前环境可用的本地图像查看方式，也未确认预览结果。
  3. 直接判定任务无法继续，转嫁用户要求重新上传。
- **评测结论：**
  - 归因：**停止条件判断过松**。未穷尽本地可用方案即判定受阻。
  - 影响：任务可完成性被错误低估，用户体验受损。
- **修复状态：** ✅
- **修复方案：** 修改 Info-skill workflow。

### D5 单次传入图片量过大导致websocket连接中断

- **所属模块 / 类型：** 资源 / 环境 / codex能力限制
- **严重程度：** 中
- **是否可复现：** 是
- **问题描述：** 一次性传入图片量过大，触发 `stream disconnected before completion: IO error: 你的主机中的软件中止了一个已建立的连接。 (os error 10053)`。
- **复现步骤：**
  1. 一次性传入大量图片。
  2. 超过 codex 承接能力。
  3. 连接层中断（os error 10053），执行需重试。
- **评测结论：**
  - 归因：一次性传入图片量过大，超过 codex 承接能力。
  - 判定依据：资源使用未做分批 / 限流，触发连接层中断。
  - 影响：执行中断，需重试。
- **修复状态：** ✅
- **修复方案：** 修改 Info-skill workflow，强化单图输入约束。
