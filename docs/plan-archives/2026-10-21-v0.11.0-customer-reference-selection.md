# v0.11.0 Plan: 简化客户参考图片选择

## Source And Status

- 归档来源：已推送到 `origin/main` 的实现提交 `444861e`（2026-09-28）。
- 版本整理日期：2026-10-21。
- 版本类型：次版本；依据版本管理指南，属于用户可感知的流程能力调整与增强。
- 当前状态：实现已在远程主分支；本地版本号与文档更新待提交、待打 tag。

## Goal

减少客户参考模式下逐张配置输出卡片的重复操作，同时保留客户对产品外观参考、仿照图顺序、色彩方向和生成前确认的控制。

## Scope And Changes

- 将 schema v4 的客户参考输入改为共用产品外形参考图、有序仿照图、单张色彩母版和全局色彩策略。
- 每张仿照图单独生成一张结果，按用户选择的顺序处理；色彩母版不增加生成数量。
- 服务端将表单提交的素材 ID 解析为本地路径，生成时只使用已解析路径。
- 更新浏览器表单、服务端、主 Skill 和客户参考工作流说明。
- 继续兼容 schema v3 的逐卡客户参考任务，不转换旧任务数据。

## Additional Scope Included In v0.11.0

本版本同时包含 `extract-product-info` Skill 的缺陷修复，依据 `docs/缺陷修复报告-20261021.md`：

- 强制单图视觉读取与逐图过程记录，确保最终记录有逐图证据来源。
- 补充读图失败时的替代路径和有效性判断，避免把 `queued`、路径或解码成功误认为已完成视觉检查。
- 增加全部图片检查和逐图记录的完成门槛；遇到实际限制时输出可续接的未完成检查点。
- 禁止输出图片/Base64 二进制内容到终端文本，并要求穷尽可用读取路径后再标记不可读。
- 将上述修复与 `egen-commerce-images` 客户参考图功能一并纳入 `0.11.0`；该版本尚待提交及打 tag。
