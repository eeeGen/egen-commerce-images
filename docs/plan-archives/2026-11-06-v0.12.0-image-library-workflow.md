## Goal

Let users find or select a local image library from the product task form and browse its styles and reference images without relying on a fixed library path.

## Scope And Changes

- Discover marked image-library folders from candidate local locations, with folder selection and binding as a fallback.
- Add library discovery, binding, refresh feedback, and image previews to the task form.
- List all style images and lazy-load thumbnails for large libraries.
- Prevent repeated folder-picker dialogs and require the local form service to start and pass its health check before task intake.
- Update the plugin prompt, relevant Skill workflow, and library design documentation.
