# v0.13.0 高定字体母版与套图取景

2026-11-07 正式发布，次版本，轻量标签为 `v0.13.0`。构建为 `0.13.0+codex.20261107021908`。

## 实现范围

- 高定的图库和手动风格目录共用选图控件。字体母版选填，支持与现有图片角色重合。前端管理选择、清空和刷新，服务端解析本次扫描的图片。见[高定规范](../../.trellis/spec/customer-reference-library.md#高定字体母版)。
- 内置按图片类型与数量分配图位，高定按仿照图或旧任务卡片的顺序分配。逐图确认同一卖点的主体、取景与实物依据，再交给各张初始 prompt。见[套图规范](../../.trellis/spec/image-set-shot-planning.md)。

## 验收

- 21 项 Python 测试通过。Playwright 在真实表单中验证图库刷新、失效提示、切换来源、手动目录重扫、母版路径写入磁盘以及内置模式保存。
- 高定的三张仿照图均展示完整的模拟测试套装，三张首轮成图分别展示整套、按键局部和单独刷头。标题采用粗斜衬线，正文采用等宽字形。红色字体样张只提供字形，画面采用色彩母版的蓝调。
- 内置 `style1` 使用同一套装参考生成两个 Feature 变体，实图分别展示手柄上的按键和随附刷头。
