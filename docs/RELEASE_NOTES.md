# Release Notes

## v0.13.0 - 2026-11-07

高定表单中，每张风格图片现在都可以设为字体母版。选中后，整套标题、正文分别匹配母版的可见字形，字色按画面可读性选择。留空时各图沿用自己的仿照图字体，色彩仍按原有策略处理。

内置和高定模式都会在生成前列出每张图要讲的卖点、要拍的主体和镜头。即使只提供一张完整套装照，总览仍可展示全套，按键图可以只拍按键，配件图可以只拍随附配件。这些取景要求直接进入各图的首轮生成。

本版本已发布，源代码版本标签为 `v0.13.0`。

## v0.12.0 - 2026-11-06

新增图库选择能力。产品任务表单可以发现带有图库标记的本地图库，浏览风格和参考图片，并在首次使用时选择、绑定图库目录。图片目录位置改变后，也可以重新发现或手动选择。

同时改进了表单启动与加载过程：启动失败时更早提示，选择图库时避免重复弹窗，风格图片列表支持超过 30 张并按需加载缩略图。

本版本已发布；源代码版本标签为 `v0.12.0`。
