# 图库设计

图库style菜单要求：跨电脑、不固定路径、免手动输入，核心思路是：**用"环境变量 + 配置文件 + 多路径探测"三层机制，让技能自动发现图库位置，而不是写死路径。**

---

## 一、整体架构

```
技能启动
  ↓
1. 读环境变量 IMG_LIB（最高优先级，适合临时/CI）
  ↓ 未设置
2. 读用户级配置文件（跨机器同步的那份，记录相对路径/盘符无关信息）
  ↓ 未命中
3. 自动探测常见位置 + 卷标/隐藏标记文件
  ↓ 仍未找到
4. 交互式引导一次，并写回配置文件（下次免输入）
```

关键点：**配置文件里不存绝对路径，而存"发现规则"**，这样换电脑也能用。

---

## 二、图库端的"自描述"设计

让图库文件夹自己"会说话"，技能靠标记文件识别它，而不依赖路径。

1. 在图库根目录放一个标记文件，例如 `.imglib.json`

2. 技能探测逻辑：在候选根目录下**递归查找（限深度）**这个标记文件，找到即认定为图库。这样图库挪到哪个盘、哪个文件夹都能被认出。

---

## 三、三级发现机制实现

### 1. 环境变量

```python
import os
lib = os.environ.get("IMG_LIB")
```

适合：CI、临时切换图库、多图库场景。

### 2. 用户配置文件

放在用户目录，里面只存"发现规则"而非绝对路径：

`~/.codex/skills/image-library/config.json`

```json
{
  "search_roots": [
    "~/Pictures",
    "~/Documents",
    "~/Desktop",
    "D:/",
    "E:/",
    "/Volumes"
  ],
  "marker_file": ".imglib.json",
  "max_depth": 4,
  "last_known": {
    "volume_label": "IMGLIB",
    "relative_hint": "codex/reference"
  }
}
```

- `search_roots` 用 `~` 展开，跨平台友好。
- `last_known` 记录"卷标 + 相对提示"，换电脑后若盘符变了仍能靠卷标定位。

### 3. 自动探测算法

```python
import os, json, glob

MARKER = ".imglib.json"

def find_library(config):
    # 1) 环境变量
    env = os.environ.get("IMG_LIB")
    if env and os.path.isfile(os.path.join(env, MARKER)):
        return env

    # 2) last_known：按卷标找盘，再拼相对路径
    lk = config.get("last_known", {})
    if lk.get("volume_label"):
        for drive in list_drives():
            if get_volume_label(drive) == lk["volume_label"]:
                cand = os.path.join(drive, lk.get("relative_hint", ""))
                if os.path.isfile(os.path.join(cand, MARKER)):
                    return cand

    # 3) 遍历 search_roots，限深度找标记文件
    for root in config["search_roots"]:
        root = os.path.expanduser(root)
        if not os.path.isdir(root):
            continue
        hit = scan_for_marker(root, MARKER, config["max_depth"])
        if hit:
            return hit
    return None
```

`scan_for_marker` 用 `os.walk` 并限制 `depth`，跳过 `.git`、`node_modules` 等目录加速。

### 4. 首次引导 + 回写

找不到时，技能提示用户"拖入图库文件夹"（GUI）或输入一次路径，然后：

- 校验标记文件是否存在（不存在则自动创建）；
- 读取该路径所在**卷标**和**相对提示**，写回 `last_known`；
- 同时把该路径的父目录加入 `search_roots`（可选）。

下次启动直接命中，无需再输入。

---

## 四、跨平台注意事项

| 项       | Windows                                                      | macOS             | Linux                  |
| -------- | ------------------------------------------------------------ | ----------------- | ---------------------- |
| 盘符     | `D:/`                                                        | 无，用 `/Volumes` | 挂载点 `/mnt` `/media` |
| 卷标读取 | `GetVolumeInformation` / `os.stat` 不行，用 `win32api` 或 `powershell` | `diskutil info`   | `lsblk -o LABEL`       |
| 用户目录 | `%USERPROFILE%`                                              | `~`               | `~`                    |

建议：

- 卷标读取做**可选增强**，失败就退回"遍历 search_roots"。
- 路径统一用 `pathlib.Path`，避免分隔符问题。
- 配置文件放 `~/.codex/...`，用云盘同步（OneDrive/iCloud/Dropbox）即可跨机器共享"发现规则"。

## 五、给 Codex 技能的接口设计

技能对外暴露一个函数/命令即可：

```python
def get_image_library() -> Path:
    cfg = load_config()          # 用户级配置
    lib = find_library(cfg)      # 三级探测
    if lib:
        return Path(lib)
    lib = interactive_pick()     # 首次引导
    save_last_known(lib, cfg)    # 回写
    return lib
```

技能内部所有取图逻辑都调 `get_image_library()`，不出现任何硬编码路径。

## 六、多图库 / 团队共享

- **多图库**：配置里 `libraries: [{name, volume_label, relative_hint}]`，技能按 `--lib name` 选择。
- **团队共享**：把图库做成 Git LFS 仓库或网盘同步目录，标记文件随仓库走；每人本地 clone 到不同路径，靠标记文件自动识别，天然满足"路径不固定"。
- **索引缓存**：首次扫描后在 `~/.codex/skills/image-library/index.json` 缓存文件清单（含 mtime），后续增量更新，避免每次全量扫盘。

---

## 七、落地清单

1. 图库根目录加 `.imglib.json` 标记文件。
2. 技能里实现 `find_library()`（环境变量 → last_known 卷标 → search_roots 扫描）。
3. 首次找不到时引导一次并回写 `last_known`。
4. 配置文件放用户目录并纳入云同步。
5. 所有取图入口统一走 `get_image_library()`。

这样每台电脑**不用手输路径**，也**不要求图库固定路径**——只要图库带着标记文件，技能就能自己找到。

## 八、为非技术人员提供显示入口

给非技术人员的入口，核心原则是：**不让他们看到"路径"这个概念**，只让他们做"选文件夹"这一个动作。

### 方案一：首次运行弹"选文件夹"对话框

技能第一次找不到图库时，直接弹系统原生文件夹选择框，用户点几下就完事，全程不碰路径。

```python
import tkinter as tk
from tkinter import filedialog
from pathlib import Path

def ask_library_folder():
    root = tk.Tk()
    root.withdraw()                     # 隐藏主窗口
    root.attributes("-topmost", True)   # 置顶，避免被挡
    folder = filedialog.askdirectory(
        title="请选择你的参考图库文件夹（选到图库根目录即可）",
        mustexist=True
    )
    root.destroy()
    return Path(folder) if folder else None
```

拿到 folder 后：

1. 检查里面有没有 `.codex-imglib.json`，没有就**自动创建**（用户无感）；
2. 写入 `last_known` 配置；
3. 下次启动直接命中，不再弹窗。

**优点**：零学习成本，Windows/macOS/Linux 通用（tkinter 自带）。
**注意**：无桌面环境（纯命令行/服务器）下 tkinter 不可用，需要方案二兜底。

---

### 方案二：纯命令行环境的"傻瓜输入"

没有 GUI 时，用**引导式提问 + 自动展开**降低门槛：

```python
def ask_cli():
    print("第一次使用，需要指定图库位置。")
    print("提示：可以直接把文件夹拖进终端窗口，会自动填入路径。")
    raw = input("图库文件夹路径：").strip().strip('"').strip("'")
    p = Path(raw).expanduser()
    if not p.is_dir():
        print(f"❌ 没找到文件夹：{p}")
        return None
    return p
```

关键细节：

- 提示里教用户"**拖进终端**"，Windows/macOS 终端拖拽会自动粘贴带引号的路径，程序 `strip('"')` 处理掉即可；
- 用 `expanduser()` 支持 `~`；
- 校验失败给**人话提示**，不要抛异常堆栈。

---

### 方案三：放到"约定俗成的默认位置"（零输入）

如果用户连选都不想选，可以约定：**把图库放进这几个默认文件夹之一，技能自动认领**。

```
~/Pictures/图库/
~/Documents/图库/
桌面/图库/
D:/图库
E:/图库
```

启动时先扫这几个位置，命中就用，**完全不打扰用户**。首次可弹一个说明："把图库文件夹放到『图片/图库』即可自动识别，或点这里手动选择"。

**优点**：真正零输入，适合批量分发给很多非技术同事。
**注意**：用户得按约定放，需要一句清晰指引。

---

## 几个易踩的坑

1. **路径含中文/空格**：全程用 `pathlib.Path`，别用字符串拼接。
2. **选到了子目录**：校验时向上找标记文件，或提示"请选图库根目录（包含 .cimglib.json 的那层）"。
3. **弹窗被主程序挡住**：`root.attributes("-topmost", True)`。
4. **无 GUI 环境调 tkinter 会崩**：先 `has_display()` 判断（检查 `DISPLAY` 环境变量或 `platform.system()`），再决定走 GUI 还是 CLI。
